# FoldTeX glossary

## Note

A saved or unsaved FoldTeX document. Every note has a title, a note kind, and
an optional course or subject.

## Note kind

The purpose of a note. FoldTeX supports `lecture` and `problem-solving`.
Existing notes without a stored kind are lecture notes.

## Lecture note

A note tied to a lecture. It can have a lecture name and lecture date.

## Problem-solving note

A note tied to a problem-solving session. It can have a problem set or topic
and a session date.
